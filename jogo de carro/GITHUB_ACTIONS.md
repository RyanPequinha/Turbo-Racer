# Turbo Racer — GitHub Actions

1. Crie um repositório no GitHub.
2. Envie todos os arquivos desta pasta para o repositório.
3. No GitHub, abra a aba **Actions**.
4. Selecione **Build Turbo Racer APK**.
5. Clique em **Run workflow**.
6. Espere a compilação terminar.
7. Abra a execução concluída e baixe o artefato **Turbo-Racer-APK**.
8. Dentro dele estará o arquivo `.apk`.

O código original do jogo (`bagui.py`) não foi reescrito.
